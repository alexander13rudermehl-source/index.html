MICBATTLE v0.3.6 · pre-alpha (LiveKit-ветка)
Внутренний тест · обновлено 03.09.2026
Выдача ролей (moderator/admin/superadmin) возвращена в админ-панель (battle-admin-bot) — доступно только Супердоступу. Для этого поле role в database.rules.json перестало быть защищённым от изменения; подробности и цена этого решения — в README battle-admin-bot.
v0.3.5 — вкладка «Кланы» разбита на отдельные кнопки: Мой клан/Создать, Таблица, Список
v0.3.4 — код клана в формате PLRK-XXXXXX, «Список кланов» независимо от очков
v0.3.3 — модерация создания кланов и ссылок на их Telegram-чаты
v0.3.2 — вкладка «Кланы» в Сообществе: создание/вступление, состав, рейтинг, управление лидером
v0.3.1 — экран итога боя с начисленными очками вместо молчаливого закрытия
v0.3.0 — лиги по очкам, зрители и таймер боя, друзья по заявкам, устранены гонки состояний в поиске соперника/рефери, экран загрузки при старте приложения
v0.2.5–0.2.6 — "Играть с другом" объединяет создание/вход по коду; добавлен "Рейтинговый бой" — очередь случайных соперников через Firebase; роли (admin/superadmin) теперь выдаются только вручную через Firebase Console
v0.1.8 — убран глючивший transaction() при входе в комнату → read-then-write; вернулась автоочистка гостевых аккаунтов (24ч)
v0.1.7 — TURN-сервер (Open Relay) + очередь ICE-кандидатов + диагностика voice-ошибок
v0.1.0 — первая версия с ручным номером в Настройках
